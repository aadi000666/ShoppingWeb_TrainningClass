# Myntra Clone Project Presentation

1. **Project Title** — Myntra Clone
2. **Student/Developer** — Aadi
3. **Objective** — A responsive fashion e-commerce storefront
4. **Project Overview** — Front-end Myntra-inspired shopping website
5. **Technologies Used**
   - HTML5
   - CSS3
   - JavaScript
   - Browser Local Storage
6. **Website Features**
   - Responsive header and navigation
   - Product category filters
   - Live product search
   - Product cards with price and ratings
   - Add-to-bag functionality
   - Persistent shopping bag
   - Toast notifications
7. **Project Structure**
   - `index.html` — page structure
   - `styles.css` — layout, colors and responsiveness
   - `script.js` — products, filtering and cart logic
   - `README.md` — project documentation
8. **Working**
   - Browse products
   - Search or select a category
   - Add products to the bag
   - Bag count and total are updated
   - Cart data remains after refresh
9. **Language Distribution**
   - CSS: 47.8%
   - JavaScript: 33%
   - HTML: 19.2%
10. **Responsive Design**
    - Desktop
    - Tablet
    - Mobile
11. **Live Demo**
    - https://aadi000666.github.io/ShoppingWeb_TrainningClass/
12. **Conclusion**
    - Built using simple front-end technologies
    - Demonstrates search, filtering, responsiveness and local storage
