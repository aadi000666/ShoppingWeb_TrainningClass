# Myntra Clone

A responsive Myntra-inspired fashion storefront built with plain HTML, CSS, and JavaScript.

## Features

- Myntra-inspired category navigation and product layout
- Search products by name or category
- Filter products by Men, Women, Kids, Home & Living, and Beauty
- Add products to a persistent bag using browser local storage
- Responsive desktop and mobile design
- Accessible labels and live cart notifications

## Run locally

No dependencies or installation are required. Open `index.html` in a browser, or serve the project directory with a local static server.

## Project files

- `index.html` — storefront structure
- `styles.css` — Myntra-inspired responsive styling
- `script.js` — product data, search, filters, and bag interactions

## Note

This is a front-end demo. It is not affiliated with Myntra and does not process real orders or payments.
